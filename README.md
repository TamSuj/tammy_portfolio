This is a personal portfolio landing page built with [Next.js](https://nextjs.org) and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the hero section by modifying `app/page.tsx`. The page auto-updates as you edit the file.
